# XimiLib - Hệ Thống Quản Lý Thư Viện (Đồ án PBL)

Hệ thống Web Quản lý Thư viện phục vụ đồ án PBL, trường Đại học Bách khoa - Đại học Đà Nẵng.

## 👥 Thành Viên Dự Án
- **Lê Võ Thành Nam**: `BE` – Backend, Logic nghiệp vụ thư viện & API.
- **Phan Vũ Xuân Kiên**: `FE/DB` – Giao diện người dùng Web & Thiết kế CSDL MySQL.
- **Nguyễn Việt Nhật**: `TechLead` – Kiến trúc hệ thống, Review code & Quản lý tiến độ.

## 🚀 Công Cụ Quản Lý Đồ Án & Tiến Độ Nhóm (PBL Workspace)
Dự án được tích hợp sẵn công cụ quản lý trực quan dưới dạng Single-Page Web App độc lập:
- **Đường dẫn:** [`plans/pbl_workspace.html`](file:///home/arjunsharma/Tài liệu/GitHub/XimiLib/plans/pbl_workspace.html)
- **Cách sử dụng:** Mở trực tiếp file `plans/pbl_workspace.html` bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox, Brave,...). Không cần cài đặt server.
- **Tính năng nổi bật:**
  - 📊 **Dashboard & Tiến độ:** Đếm ngược ngày bảo vệ, % hoàn thành đồ án, theo dõi task khẩn cấp.
  - 💡 **Tính Năng Ưu Tiên (1 Cột):** Sắp xếp mức độ ưu tiên từ trên xuống dưới, phân loại MoSCoW, ghi chú lý do lược bỏ tính năng.
  - 📅 **Lịch Trình Theo Tuần (W1–W11+):** Phân công công việc chi tiết cho Nam, Kiên, Nhật; lọc theo thành viên và xuất báo cáo nộp giảng viên.
  - 🗄️ **Sơ Đồ CSDL Tương Tác Kiểu SSMS:** Kéo thả bảng, cuộn chuột giữa để Zoom In/Out theo tâm con trỏ, tự động nối đường quan hệ SVG, chọn nhanh kiểu dữ liệu, Import file `.sql` từ MySQL và xuất mã SQL DDL.
  - 📁 **Kho Tài Liệu & Tài Nguyên:** Quản lý liên kết Figma, GitHub, tài liệu SRS, hình ảnh mockup và file script.
  - ✅ **Tiêu Chí DoD & Test Cases:** Nghiệm thu tiêu chuẩn hoàn thiện và kiểm thử các kịch bản thư viện.
  - 💾 **Lưu Thông Minh Đẩy Git (Phím tắt `Ctrl + S`):** Tự động lưu ngầm vào trình duyệt; nút **"Lưu Vào File (Đẩy Git)"** ghi đè trực tiếp vào file HTML để sẵn sàng `git push` đồng bộ cho cả nhóm.
